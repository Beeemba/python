## 🔧 Описание проделанной работы

В ходе выполнения лабораторной работы были отработаны следующие темы:
- Работа с числовыми типами данных и арифметическими операциями
- Строки и срезы (включая обратные срезы с шагом)
- Списки: методы insert(), extend(), emove(), index()
- Словари: вложенные структуры, итерация по ключам и значениям
- Множества: операции |, &, - (объединение, пересечение, разность)
- Функция ound() для округления чисел
- F-строки для форматированного вывода

Каждое задание реализовано в отдельном файле и запускается независимо.
